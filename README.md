# 🏆 TournamentStats — статистика спортивного турнира

**TournamentStats** — учебная программа для подсчёта результатов спортивного турнира. Она формирует **таблицу команд**, считает голы, очки, победы, поражения и ничьи, а также находит самые результативные матчи.

## ✨ Возможности

- Подсчёт очков каждой команды.
- Подсчёт побед, поражений и ничьих.
- Расчёт забитых и пропущенных мячей.
- Расчёт разницы мячей.
- Расчёт средней результативности матчей.
- Поиск топ-N матчей по количеству голов.
- Распределение матчей по этапам турнира.
- Фильтрация матчей по команде и минимальному количеству голов.

2. Клонируйте репозиторий
3. Установите зависимости

```bash

cd devdiary
pip install -r requirements.txt
```

Внешние библиотеки устанавливать не нужно: используются только модули стандартной библиотеки Python.

## 💻 Использование

Функция принимает список матчей и параметры фильтрации:

```python
report = tournament_stats(
    matches,
    team_filter=None,
    min_goals=0,
    top_n=5,
    include_draws=True,
    points_win=3,
    points_draw=1
)

print(report["standings"])
print(report["top_matches"])
```

| Параметр | Описание |
|---|---|
| `matches` | Список матчей |
| `team_filter` | Название команды для фильтрации или `None` |
| `min_goals` | Минимум голов в матче |
| `top_n` | Количество матчей в топе |
| `include_draws` | Включать ли ничьи в топ матчей |
| `points_win` | Очки за победу |
| `points_draw` | Очки за ничью |

## 🏗️ Архитектура

> Программа получает список матчей, проверяет данные, рассчитывает статистику команд и возвращает итоговый словарь.
>
> Внутри обработка разделена на несколько последовательных этапов.

```text
Входные матчи
     |
     v
Проверка и фильтрация
     |
     v
Подсчёт статистики команд
     |
     v
Сортировка таблицы и матчей
     |
     v
Итоговый словарь
```
